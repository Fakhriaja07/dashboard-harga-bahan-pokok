# Dashboard Harga Bahan Pokok & Inflasi Indonesia

Dashboard harga bahan pokok nasional dan Riau, beserta konteks inflasi.
Dibuat oleh Fakhri — Data Analyst.

## Data

- **Harga nasional (PIHPS, Bank Indonesia)** — 21 komoditas, per 17 November 2026.
- **Inflasi (BPS)** — Oktober 2026: umum 3,23% (y-on-y), pangan bergejolak 5,81%, inti 2,56%; inflasi cabai rawit 104,35% (y-on-y).
- **Riau (PIHPS per provinsi)** — per 16 November 2026, dibanding Kepulauan Riau.
- **Riau vs Nasional (Panel Harga Pangan Bapanas)** — per 17 November 2026.
- **Kota Pekanbaru (Disperindag)** — rekap 11 pasar, 16 November 2026.
- **Operasi Pasar Murah Pemprov Riau** — 16–20 November 2026.

Data bersifat snapshot 16–17 November 2026. Angka PIHPS dan BPS berbeda
karena periode dan cakupan pencatatan berbeda — keduanya diberi label
sumber masing-masing di halaman.

## Menjalankan

Situs statis satu file (`index.html`). Buka langsung di browser, atau
deploy ke hosting statis apa pun (Vercel, Netlify, GitHub Pages).
